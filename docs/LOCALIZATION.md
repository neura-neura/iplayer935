# Idiomas de la interfaz (compilación26)

**Servidores → ⋯ → Idioma** ofrece Idioma del sistema (predeterminado), Español, English y 简体中文. La elección explícita se guarda solo para esta app con IPInterfaceLanguagePreference; no modifica AppleLanguages ni el idioma global del iPod. La selección se marca y se aplica al instante. Los nombres de las tres lenguas se muestran en su propio idioma para facilitar volver a cambiar.

En modo sistema se usa el primer idioma de NSLocale.preferredLanguages: es-* selecciona español, zh-* chino simplificado (también zh-Hant) y cualquier otro inglés. Se comprueba al iniciar y al volver a primer plano. Las preferencias desconocidas vuelven al modo sistema. El usuario informó que25 no cambiaba de idioma al modificarlo en el iPod: la causa exacta en iOS9 no se reprodujo en host. El selector permite elegirlo sin depender de esa detección.

IPStringCatalog lee el archivo Localizable.strings de la carpeta lproj elegida mediante su ruta explícita, sin negociación ni caché de idioma de NSBundle. Conserva el catálogo inglés de respaldo y una instantánea inmutable con el catálogo activo combinado. Las consultas obtienen esa instantánea atómica y una clave en memoria; no leen preferencias ni archivos. Solo un cambio efectivo lee otro catálogo. Seleccionar de nuevo la misma opción o comprobar un idioma del sistema que sigue igual no reconstruye la interfaz ni vuelve a leer archivos. Las tres traducciones contienen341 entradas cada una. Un texto ausente recurre a inglés y, si tampoco existe allí, devuelve su clave.

La notificación de idioma reconstruye únicamente las cuatro raíces de navegación y la barra inferior; si se cambia desde el selector, este permanece abierto y traducido. Se conserva la pestaña seleccionada, pero se reinician las rutas de navegación previas. IPStore y IPPlayer permanecen vivos: no se abre otra vez la biblioteca, no se reindexa, no se restaura la sesión ni se reinicia el audio. La devolución de errores del reproductor se enlaza a la nueva interfaz. No se genera una traducción por canción.

Se traducen los textos propios de navegación, acciones, selección múltiple, reproductor, accesibilidad, fundido, cachés, preparación, escaneo, descargas y errores propios. Los datos de canciones, géneros de ID3, nombres de perfiles, playlists, rutas, identificadores persistentes, SQL, protocolos HTTP y códigos de diagnóstico se conservan. Los detalles técnicos y controles generados por componentes del sistema pueden conservar su idioma de origen o del iPod. El motivo persistente de formato incompatible conserva su clave original y se traduce al mostrarlo. El crédito mantiene «neura-neura» en todos los idiomas para conservar el enlace.

Validación: python3 Tests/check-localizations.py comprueba integridad de catálogos, argumentos printf y crédito. Tests/run-localization-tests.sh comprueba selección por idioma principal, las tres opciones explícitas, cambio inmediato, vuelta a sistema, ausencia de notificación al repetir una opción, consultas concurrentes durante cambios, respaldo inglés, preferencia inválida y conservación de la elección en otro proceso. La revisión visual y continuidad acústica requieren el iPod.


Desde27 las cuatro pestañas usan UITabBarItem con título e imagen explícitos, evitando que los elementos de sistema impongan «Marcadores» u otros títulos del idioma de iOS. Sus títulos y etiquetas de accesibilidad se reconstruyen con el idioma seleccionado. Los iconos vectoriales se rasterizan una sola vez y se comparten entre reconstrucciones de interfaz.
